# Город Греха (Sin City)

Быстрый FPS-роглайт про казино дьявола: колода карт вместо пистолета, масти врагов, джокер-ставка на цвет и забег через бесконечные залы казино.

## Как открыть проект

1. Unity **6000.3.8f1** (URP).
2. **Tremble** (Tiny Goose) — платный пакет для карт TrenchBroom, в репозиторий не входит. Купи его и положи в `Assets/Tremble`.
3. Открой проект, дождись импорта и выбери в меню **Sin City → Setup Prototype**: оно создаст карты колоды, префабы врагов и пропов, `GameConfig`, синхронизирует энтити с TrenchBroom и соберёт сцены.
4. Сцена **Hub** — комната героя. Красный портал «ЗА СТОЛ» начинает забег. Сцена **Prototype** — ручной тестовый уровень из трёх арен.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение / прыжок (двойной) | WASD / Space |
| Рывок / подкат, быстрое падение | Shift / Ctrl |
| Бросок карты / перетасовать колоду | ЛКМ / R |
| Джокер | F |
| Карты / пулемёт фишек | 1 / 2 / колесо / Q |
| Взаимодействие / пауза | E / Esc |

## Карты уровней

Карты рисуются в TrenchBroom. Черновики генерируются скриптами:

```bash
python Tools/gen_run_maps.py        # хаб и шаблоны комнат забега
python Tools/gen_prototype_map.py   # ручной тестовый уровень
```

Шаблон комнаты забега — `.map` в `Assets/Maps/Rooms` с энтити `room_info`, `room_entry`, `room_exit` (slot 0–2) и `enemy_spawn` с полем `role` (Any / Melee / Ranged / Heavy). Повторный запуск скриптов перезаписывает файлы.
